# Brief To Work Order

Turn a request or agreed plan into an assignment someone can execute, with
bounded scope, clear deliverables, and acceptance checks a person can actually
verify.

Give it the request or plan, the intended outcome, and any settled
constraints. It surfaces choices that materially affect the work instead of
silently deciding them.

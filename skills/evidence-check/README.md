# Evidence Check

See which claims in a draft, report, plan, or decision have real support. The
skill links each claim to evidence you can inspect and keeps direct support,
inference, assumptions, and unknowns separate.

Give it the material and say what decision it needs to support. If browsing or
source access is unavailable, the skill marks that limitation instead of
pretending to verify the claims.

- Instructions: [SKILL.md](SKILL.md)
- Worked example: [EXAMPLE.md](EXAMPLE.md)

```bash
npx skills add Kaagemusha/agent-skills --skill evidence-check
```

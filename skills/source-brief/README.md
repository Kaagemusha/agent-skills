# Source Brief

Turn a long article, report, transcript, or document into a short brief a
person can read fast, without losing what matters. Before drafting, the skill
lists the facts, numbers, caveats, and attributions whose loss would mislead.
After drafting, it checks every sentence against the source and removes
anything that got stronger, vaguer, or invented along the way.

It compresses; it does not advise. For recommendations use Decision
Deliberation, and for checking a draft's claims use Evidence Check.

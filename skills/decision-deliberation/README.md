# Decision Deliberation

Prepare a consequential decision before a plan is chosen. The skill runs five
lenses over the question (incentives, system boundaries, historical patterns,
second-order effects, cognitive bias), maps the tensions that remain, and
ends with options and the evidence that would change the view.

It never makes the decision. The output states plainly what the decision
owner still has to choose.

Once one plan or draft is chosen, switch to Red Team Review. Comparing
several candidate plans still belongs here.

- Instructions: [SKILL.md](SKILL.md)
- Worked example: [EXAMPLE.md](EXAMPLE.md)

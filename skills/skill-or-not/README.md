# Skill Or Not

Decide whether a prompt you keep reusing should become a skill. The skill
tests the candidate with one sentence (for this task, with this input, use
this method to produce this output, unless these conditions apply), checks
seven readiness conditions, looks for overlap with skills you already have,
and places it on a ladder from saved prompt to skill to scheduled routine.

Most candidates should stay one layer lower than their author hopes. That is
how a skill library stays small enough for agents to choose from correctly.

- Instructions: [SKILL.md](SKILL.md)
- Worked example: [EXAMPLE.md](EXAMPLE.md)

Install only this skill:

```bash
npx skills add Kaagemusha/agent-skills --skill skill-or-not
```

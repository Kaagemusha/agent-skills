# Handoff

Use this skill when pausing a task or passing it to another person or agent.
It writes a concise continuation note, and it requires whoever receives the
note to check its important claims against the current source of truth before
acting.

Tailor the output shape to your team's tools, but keep the verification and
permission boundaries.

- Instructions: [SKILL.md](SKILL.md)
- Worked example: [EXAMPLE.md](EXAMPLE.md)

Install only this skill:

```bash
npx skills add Kaagemusha/agent-skills --skill handoff
```

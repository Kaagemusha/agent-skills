# Retrievable Writing

Make knowledge-base notes work for AI agents, which usually retrieve one
section and act on it with no memory of the rest. The skill checks that each
note opens with its claim, that every section names its own subject, that
terms are resolved where they are used, and that nothing is ever cut to save
space.

Use it for notes, documentation, and wiki pages that agents read. Do not use
it for essays, emails, or anything written for a person reading from the top.

- Worked example: [EXAMPLE.md](EXAMPLE.md)

# Grounded Research

Answer an open question by finding and inspecting the few sources that can
settle it. It prioritizes primary evidence, checks material claims against the
source itself, and keeps fact, inference, and uncertainty separate.

Use it when you need research from scratch. For sources you already have, use
Source Brief to summarize them or Evidence Check to test claims in a draft.
